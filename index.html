SHEET 03/07

Pet project, taken seriously

Detail A · FlowSync
Open source · NestJS + React · in active development

FlowSync

A Jira-style task tracker: projects, tasks, comments, tags, assignees, a board, notifications and activity feeds. I use it as a lab to practise production-grade architecture, and every decision is written down in 47 ADRs.

  • Auth: short-lived access token, httpOnly refresh cookie with rotation; reuse of a spent token kills the whole session.
  • Closed-by-default API, per-project access rules that answer 404 to outsiders, CASL permissions.
  • Transactional outbox, domain events, Redis queue, Socket.IO realtime that works across instances.
  • Optimistic concurrency, cursor pagination, request IDs in every log and error.
  • Prometheus and Grafana, load scenarios, backup and restore verification, security scans.
  • Vitest, MSW, axe, Playwright, mutation testing, CodeQL and release-please in CI.
